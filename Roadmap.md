## Roadmap / Future Development

### Planned: Multilingual Support

One of the planned future improvements for UVUM is the implementation of a multilingual user interface.

The goal is to allow users to choose their preferred language directly within the application.

Additional languages will be introduced progressively.

*This feature is planned for a future version and is not yet available in v0.10.0.*

## Hoja de ruta / Desarrollo futuro

### Próximamente: Soporte para varios idiomas

Una de las mejoras previstas para futuras versiones de UVUM es implementar una interfaz de usuario multilingüe.

El objetivo es permitir que cada usuario pueda seleccionar su idioma preferido directamente desde el programa.

Se irán incorporando nuevos idiomas progresivamente.

*Esta característica está prevista para una versión futura y todavía no está disponible en la v0.10.0.*
